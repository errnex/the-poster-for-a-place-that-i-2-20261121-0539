# LUMEVARA — The Poster for a Place That Isn't There

A vintage travel poster for **Lumevara**, a floating tide-garden archipelago that does not exist: garden islands drift on the evening tide, waterfalls spill from their edges into the sea below, and a single lantern-tree lighthouse guides the little sailboats home at dusk.

The poster artwork is drawn from scratch (Python PIL) in a flat vintage style — deep teal dusk, warm peach horizon, one glowing landmark — and `main.ts` copies the finished `entry.png` to the output directory with Node stdlib only, so both sandbox runs produce identical bytes.
